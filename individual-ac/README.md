# 標準住宅の断熱・気密比較（個別空調）

vtsimNX の標準住宅 example を基に、床断熱4仕様（等級4〜7）と外皮隙間6倍率を組み合わせた。年間集計は各8,760時間。最寒週2月19〜25日と最暑週7月27日〜8月2日は各168時間。

- エアコンはLD・寝室・子供室1・子供室2の4台。機種、制御、24時間換気、局所換気、室間の固定風量、床下・小屋裏換気は example の設定を使用。
- 隙間倍率は 0 / 0.5 / 1 / 2 / 4 / 8。公称C値は 0.00 / 0.30 / 0.59 / 1.19 / 2.37 / 4.74 cm²/m²。窓・玄関扉など外皮19開口を各12区画に分け、外皮の通気係数だけに倍率を適用。
- 気象ファイルは標準住宅Colabの `3639999.has`、風圧係数は同じColabの風圧係数CSVを参照した既存比較用の16方位表。再計算に用いた両ファイルのSHA-256は [ua.json](ua.json) に記載。
- 等級4×0のビルダー出力は元の example を同じ気象ファイルで処理した出力と一致。比較した入力のSHA-256とvtsimNXのコミットは [ua.json](ua.json) に収録。
- 床断熱のUA値は等級4から順に 0.89 / 0.62 / 0.46 / 0.34 W/(m²·K)。玄関土間を1.365×1.820 mと仮定し、外気側・換気床下側の長さを各3.185 m、線熱貫流率を0.99 W/(m·K)、温度差係数を順に1.0、0.7とした。土間外周の仮定はUA評価に用いた。詳細は [ua.json](ua.json)。
- 年間負荷は暖房顕熱と冷房顕熱・潜熱を集計。消費電力量は4台の合計。相対湿度は温度と重量絶対湿度から算出。年間の増減率は同じ等級の×1を基準とした。
