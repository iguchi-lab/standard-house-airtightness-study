# 標準住宅の断熱・気密比較（個別空調・基礎断熱）

前回の[床断熱・個別空調24条件](../individual-ac/)と同じ標準住宅を、vtsimNX の `foundation4`～`foundation7` に切り替え、外皮隙間6倍率の24条件を年間計算した。

- 1階床は合板・木部を残し、床の断熱材を除いた。各等級の外壁一般部の断熱材と同等の熱抵抗を持つXPS3種を基礎外壁の外側に配置した。厚さは等級4～7で順に47.3、102.4、122.4、157.4 mm。
- 床下外気換気（床断熱版で5回/h）を停止。LD・寝室・子供室1・子供室2の個別エアコン、運転スケジュール、床下以外の固定換気、気象・風圧係数は前回と同じ設定。
- 隙間倍率は0 / 0.5 / 1 / 2 / 4 / 8。公称C値は0.00 / 0.30 / 0.59 / 1.19 / 2.37 / 4.74 cm²/m²。外皮19開口を各12区画に分け、外皮の通気係数だけに倍率を適用。
- 土間外周は35.49 m、線熱貫流率は0.99 W/(m·K)、温度差係数は1.0とした。UA値は等級4～7で順に0.89、0.65、0.50、0.39 W/(m²·K)。計算設定・基準ケースとの入力照合は [ua.json](ua.json) を参照。
- 年間8,760時間は12月15日からの助走408時間を除いた評価期間。最寒週（2月19～25日）と最暑週（7月27日～8月2日）は各168時間。増減率は同じ等級の隙間倍率×1を基準とし、暖房は顕熱、冷房は顕熱と潜熱の合計を集計した。
